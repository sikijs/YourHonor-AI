Setup (5 Steps)

Step 1: Download the ZIP above to any folder of your choice and unzip it.
Step 2: Double-click setup.command (Mac) or setup.bat (Windows). Paste your OpenRouter key when prompted.
ℹ️ Having trouble with setup? Click here

macOS — scripts blocked?

  1. Press Cmd+Space to open Spotlight
  2. Type Terminal and press Enter
  3. Click the Copy button below — this copies xattr -dr com.apple.quarantine (with a space at the end):
    xattr -dr com.apple.quarantine
  4. Go to the Terminal window and paste — you'll see xattr -dr com.apple.quarantine with a blinking cursor after the space
  5. In Finder, locate your YourHonor-AI-main folder. Click and hold the folder, drag it into the Terminal window, and drop it right after the space — the folder's full path appears next to the command
  6. The line should now look something like: xattr -dr com.apple.quarantine /Users/yourname/Desktop/YourHonor-AI-main
  7. Press Enter
  8. Now double-click setup.command to run it

Windows — setup.bat blocked?

  1. Right-click setup.bat
  2. Click Properties
  3. If you see an Unblock checkbox at the bottom, check it
  4. Click OK
  5. Now double-click setup.bat to run it

If SmartScreen still shows a warning, click More info then Run anyway.

Step 3: Double-click Start YourHonor AI.command (Mac) or Start YourHonor AI.bat (Windows). Wait for the message "YourHonor AI is running..."
ℹ The first start takes a few minutes. The very first time you run the app, it downloads and sets up everything it needs — please be patient, this can take a few minutes. Every start after that is nearly instant.
Step 4: Open your browser to http://localhost:8000 (or any available port). Click Sign Up and create an account.
Step 5: Done! Use the Chat, tools, and document generator. Double-click Stop YourHonor AI.command to shut down.
ℹ Port 8000 already in use? The app will automatically pick another port (e.g. 8001) and show you the correct address.
ℹ Tip for frequent use: Drag Start YourHonor AI.command to your Dock (Mac) or pin Start YourHonor AI.bat to your taskbar (Windows) for one-click access. Do the same for Stop YourHonor AI.command.
