Before You Start

Docker Desktop

Free. Download here — install and open it (wait for the whale icon).

OpenRouter API Key

~$5 minimum. Create a key, then add credits under Settings → Credits.

Setup (5 Steps)

Step 1: Download the ZIP above to any folder of your choice and unzip it.
ℹ macOS: setup.command blocked?
If Apple blocks setup.command after downloading and unzipping the app:

1. Press Cmd+Space to open Spotlight
2. Type Terminal and press Enter
3. Copy the line below (including the space at the end) and paste it into the Terminal window:
xattr -d com.apple.quarantine
4. Drag setup.command from your folder and drop it onto the same line in Terminal — the file path appears automatically
5. Press Enter
6. Now double-click setup.command to run it
Step 2: Double-click setup.command (Mac) or setup.bat (Windows). Paste your OpenRouter key when prompted.
Step 3: Double-click start.command (Mac) or start.bat (Windows). Wait for the message "YourHonor AI is running..."
Step 4: Open your browser to http://localhost:8000 (or any available port). Click Sign Up and create an account.
Step 5: Done! Use the Chat, tools, and document generator. Double-click stop.command to shut down.
ℹ Port 8000 already in use? The app will automatically pick another port (e.g. 8001) and show you the correct address.
ℹ Tip for frequent use: Drag start.command to your Dock (Mac) or pin start.bat to your taskbar (Windows) for one-click access. Do the same for stop.command.
